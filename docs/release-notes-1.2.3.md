# 1.2.3

## 新增：模拟测试

选一本书，让模型先读目录与前几页做一次「出卷规划」（判断学科、列 8–12 个知识点），再分 4 批出 20 道题，每题都带来源：PDF / Word 是页码，Markdown 是原文件行号。

- **判分**：单选选中即判；多选交卷时判（全对 10 分、漏选 5 分、选了错误选项 0 分）；大题先展开参考答案，再对照评分要点给自己打 0–10 分。
- **作答**：每题右侧小箭头展开答案、解析、评分要点与来源；客观题展开后本题作答锁定；顶部实时显示已得分数与完成数。交卷前有未答 / 未自评会先确认。
- **结果**：总分、按题型得分表、用时、薄弱知识点；可以回看、改大题自评（离开结果页后只读）。
- **学习记忆**：默认勾选「把这次测验的结果记入学习记忆」，离开结果页时才写入，期间可以取消；只写总分、各题型得分和薄弱知识点，不写题目与答案原文，并标明是自评。同一套反复进出只写一次。
- **导出**：结果页「导出并加入文档库」弹出系统「另存为」，生成 Markdown 试卷并加入文档库；同一个路径再导出会覆盖并复用原文档，不会出现两份。
- **出题过程**：可以先停止（已生成的题保留），单批失败可以只重试那一批，也可以换模板重出（保留知识点规划）；扫描件、加密 PDF、原文件丢失时先给出选择卡，确认后才出无来源的题。
- **保留**：「最近的试卷」最多 20 套，超出时先淘汰最早交卷的一套；书被移出文档库后，已出的试卷仍可作答与导出。
