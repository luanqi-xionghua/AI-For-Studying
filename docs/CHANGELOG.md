# 开智更新日志

开智 Windows 桌面版各版本的更新说明，按版本从新到旧排列（原先分散在 82 个 RELEASE_NOTES_*.md 中）。发布新版本时，在最上方按同样格式新增「## 开智 X.Y.Z」一节；GitHub 发布流程会用 `scripts/release-notes.mjs` 自动摘出这一节作为 Release 说明。

## 开智 0.10.54

- 背景画面新增「递归自我改进」：格子上冒出点阵的星芒，化成一团，再收成圆角方砖；方砖长满一整片后镜头拉远，这一整片成了更大一格里的一块砖，如此往复。长得越多，长得越快。灵感来自 Anthropic Institute〈When AI builds itself〉的页头动画，这里是自己重画的，节奏放慢。
- 以后新加的背景画面默认勾上；在设置里取消过的不会被重新勾上。

## 开智 0.10.53

把框选截图那种「细线 + 辉光」的感觉用到更多地方：

- 快速解释卡片：出现时从略大处收拢，外面一圈主色光晕呼吸两下再收成淡淡一圈；解释写完时一道高光从卡片上滑过；追问按钮悬停时发光。
- 输入栏里刚截的图带一圈主色细线和光晕，留住后换成红框和淡淡的红晕。
- 双击放大图片：周围虚化压暗，图片外一圈白色细线和辉光。
- 计时圆环（顶栏、左下角、卡片表盘）：进度弧发光，弧的尽头有一颗亮点。

## 开智 0.10.52

- 计时中，顶栏小钟显示一只进度圆环和现在几点（圆环代替时段图标）；鼠标停上去显示还剩多少。
- 顶栏收起时，窗口左下角有一只进度圆环（没有底，直接在背板上）；鼠标停上去显示现在几点和还剩多少，点一下打开计时卡片。

- 快速解释卡片重新设计：词条像被荧光笔划过，标题下一道细线（解释生成中有光滑过），三个追问按钮收在一枚小药丸里。

- 修复：打开阅读助手时，右侧的问题刻度有时不出现。
- GB300：去掉最远处没有细节的线，天际线降低；远处的波按距离收小，中远景不再出现摩尔纹。

## 开智 0.10.23

背景画面：

- **GB300 的遮挡**：一排里严格从两头往中间一个个把机柜画完整，靠中间的盖住外侧的，后面机柜的柜顶不会再从前面的机柜里穿出来。
- **铺满**：背景画布连左侧栏下面也铺着，侧栏边上不再留一条空白；收起侧栏时那一块也有画面。
- **波**：云卷云舒——波速降到原来的 65%，振幅减到一半左右，波长更长；一次只来一个波，歇一会儿再来下一个，起落都更慢。
- **帧率**：画面轻的时候每秒 60 帧，一般每秒 30 帧，一帧超过 16 毫秒才降到 20 帧（此前超过 6 毫秒就降到 20 帧，机柜因此显得卡）。

## 开智 0.10.22

### 背景画面 GB300

- 机柜有三个面了：柜顶、朝着画面中间的侧板、正面。一排里先画侧板、再画柜顶、最后贴正面，机柜之间不再穿帮、叠在一起。
- 最前面的一排一直画到整个机柜滑出画面下沿，不会凭空消失；远处的排从透明慢慢显出来，不再一排排地跳。
- 波不再突然冒出来：振幅从零慢慢起来，最后慢慢平息。形状有三种，随机出现在随机位置——一滴水的圆环、从画面外推进来的平面波、两滴水的干涉。
- 中景、远景和近景一样每帧都画，不再隔几帧才动一下。

### 用 Codex 登录时的对话

- 提示词改成「先答再查」：问题附带的当前位置附近内容够回答，就直接回答，不调用查阅文档的工具；确实需要别处内容时才查，次数尽量少。此前的提示词鼓励分三个阶段、最多十二次查阅，每查一次模型就要多跑一轮。
- 随问题带上的附近内容从 4000 字加到 8000 字，更多问题不用查就能答。
- 多备一条热连接：预判问题、翻译和正式提问各占一条连接，正式提问不再因为连接被占用而等小助手冷启动（几秒）。
- 用 Codex 时，预判问题多等一会儿再发，翻页时不白跑一整轮对话。

## 开智 0.10.18

### 背景画面：放慢、减弱存在感，逐个重做

- 新画面全部放慢：洛伦兹轨道、凯莱图游走、Dijkstra、墨西哥帽的小球都慢到原来的三分之一左右。
- **DNA 双螺旋**：没有尽头——整条链沿轴缓缓滑过画面，两头褪进纸里，约九十秒才转一圈。原子只用纸色、铅笔、红笔三种平涂，不打高光，右下角划几道铅笔斜线当阴影。

- **生命游戏**：直接拿桌面的格子纸当格点，一格一个细胞，不再是立体的；刚出生的细胞是红的，刚死的留一点淡影。
- **红黑树**（原「分形二叉树」）：键一个个插进来，破坏规则时重新着色，或者把一小段子树左旋 / 右旋——只有那一段在动，整棵树不转。
- **GB300**（原「机柜的海」）：近处画出机柜的样子——上下的电源框、两组计算托盘、中间的交换机段、托盘把手与网孔、柜顶的出风口和冷却液软管，每八个机柜留一条过道；细节随距离连续淡出，中景仍是一个个方头的机柜，再远才连成一线。镜头和波都慢了很多，同一时间只有一圈波。

## 开智 0.10.16

### 背景画面重画得更细

- **DNA 双螺旋**：B 型 DNA 的球棍模型——磷酸、脱氧核糖、碱基的每个重原子都是一个球，近的挡住远的；碱基对之间的氢键是虚线，红笔逐对读过去（A = T、G ≡ C）。

- **生命游戏**：一门高斯帕滑翔机枪加一片随机初始图样，下面叠着前几代，刚出生的细胞用红笔。

### 谷歌翻译连不上

### 阅读助手：附属对话（侧边对话）
- 在回答里选中一段，浮出「添加到对话」（Ctrl+↓）和「在侧边对话提问」（Ctrl+→）。Ctrl+→ 会打开附属对话：整个助手窗口用弹簧动画加宽，右边多出一栏，中间一道细线隔开，可以左右拖动调整两边宽度。
- 附属对话和主对话是同一种助手：同样的思考过程、回答、复制 / 重新生成、模型与思考强度、文档上下文开关、图片、斜杠命令，只是没有分支。顶部标题栏与主对话齐平，标明「附属对话」和它挂在哪段主对话旁边。
- 上下文各自独立：附属对话开始时继承主对话当时的上下文；之后主对话再说什么，附属对话看不到，主对话也看不到附属对话。
- 两边的内容靠 Ctrl+方向键传递：选中文字后，Ctrl+→ 带到附属对话、Ctrl+← 带回主对话、Ctrl+↓ 摘录到本对话。选中的文字像一张小纸条飞过去，落成一张「摘录卡片」，之后的提问会带上它，可以随时移除。两边的输入框都不会被改动。
- 附属对话与主对话绑定、永久保存：换回这段主对话时它还在；删除主对话时一起删除；不出现在对话记录列表里。

### 阅读助手：斜杠命令
- 在输入框里打「/」弹出命令列表，方向键选择，Tab / 回车补全。
- /btw 问题：顺便问一句。回答显示在输入框上方的便签里，不写进对话记录，Esc 关闭。
- /compress [要求]：把目前的对话压缩成一份摘要。原消息仍在（变淡），之后的提问只带摘要和其后的消息，省上下文。
- /usage：用量卡。包括当前对话占用的上下文、今天的用量（对比近两周峰值）、本次会话的请求数与用时、按模型的输入 / 输出 / 思考明细，以及用量花在哪里（主对话、侧边对话、翻译、预判……）。可以一键复制为文字。三种界面风格各有样式：草稿风格是铅笔描边的便签，进度条用斜线涂出来。

## 开智 0.8.3

全面的流畅度优化，重点是液态玻璃。逐帧实测（同一台机器、同一套操作，帧时间中位数 / 95 分位）：

| 操作 | 之前 | 现在 |
|---|---|---|
| 滚动 PDF | 100 / 183 ms | 17 / 17 ms |
| AI 流式输出 | 100 / 133 ms | 17 / 17 ms |
| 打开 / 关闭阅读助手 | 67 / 200 ms | 17 / 67 ms |
| Ctrl+B 收放侧栏 | 50 / 100 ms | 17 / 67 ms |
| 打开 / 关闭设置 | 100 / 183 ms | 17 / 67 ms |

- **预设底板上的大面板不再逐帧重算模糊**：侧栏、顶栏、工具条、阅读助手和文档库卡片身后只有柔和的渐变，实时模糊和折射看不出差别，却在页面每次重绘时整块重算。现在它们直接用玻璃的底色与高光，外观几乎一致；弹窗、菜单、页码胶囊等压在内容上的玻璃仍是实时模糊与折射。
- **图片底板**：所有玻璃仍完整生效；内容滚动、AI 输出或弹窗弹出时，折射透镜短暂停一下（模糊不变），停下后马上恢复。图片底板下滚动 PDF 从 100 ms 降到 17 ms。
- **弹窗遮罩只压暗不模糊**：全屏实时模糊是打开设置时卡顿的主要来源，弹窗自身的玻璃仍会模糊身后的内容。
- **动画不再逐帧失焦**：关闭阅读助手、收起侧栏时去掉整块面板的模糊滤镜，只保留缩放与淡出。
- **收放侧栏和助手时**，横向滚动条不再逐帧强制重排，停下后再精确测量。
- 设置里说明了预设底板与图片底板下玻璃效果的区别。

### 液态玻璃

- 玻璃有了真正的光线折射：每块玻璃（侧栏、顶栏、工具条、助手、卡片、菜单、提示……）边缘是一圈凸透镜，身后的照片、页面和光斑在边缘被拉伸、弯折；小块玻璃边缘还有很淡的色散。中间照常磨砂，文字不参与扭曲。可在「设置 → 外观 → 光线折射」关闭。

- 「泛白」现在可以自己调。它来自两样东西：玻璃本身的底色（浅色主题白、深色主题深灰），以及图片底板下的可读性补偿——身后图片和文字颜色太接近时，应用会把那块玻璃自动加厚，所以同一张图上有的面板发白、有的不发白。「设置 → 外观 → 玻璃可读性」提供：
  - 补偿方式：加厚玻璃（统一字色）/ 切换字色（玻璃保持通透，按身后明暗换深浅字色）/ 关闭；
  - 补偿强度：越低越通透，差的对比度改用一圈很淡的文字光晕补上（默认 50%，原来相当于 100%）；
  - 玻璃底色：跟随主题，或取自底图颜色（带上图片的色调，而不是一层白雾）。
- 右键菜单换成带折射的液态玻璃，跟随光标的镜面环，指向的那一项下面滑过一滴玻璃高光。
