# 1.2.9

本次更新集中在前端桌面端的五项体验与预算调整：学习模式的加入文档门禁统一、加入文档窗口加宽、阅读助手与多文件提问的默认预算取上限并按秒显示搜索时间、术语统一，以及对话模式模型抽屉补上「确定」。不涉及模型协议、数据库结构或依赖变化。

## 学习模式：所有加入入口统一检查

- 学习模式开启且两道自评或学习目标没填完时，现在**所有**会新建文档库记录的入口都会被拦下：点虚线框或键盘选择文件、把文件拖进已打开的「加入文档」窗口、直接把文件拖进主窗口或拖到全屏遮罩上松手，以及模拟测试结果页的「导出并加入文档库」。
- 被拦下时统一提示「学习模式已开启：请先完成两道自评并填写学习目标，再加入文档。」，并把焦点放到第一个没填的地方；这一步不会打开选择文件的窗口、不会入队、不会写文档库，也不会记学习记忆。填好后再操作一次即可。
- 关掉窗口、按 Esc 或关掉学习模式都不会清掉本次应用里已经填好的内容；只有一批文档真正加入后草稿才会清空，再加入下一批时需要重新回答。
- 试卷导出被门禁拦下时只打开同一张学习模式表单（不弹「另存为」、不写文件、不入库）；填好回到结果页再点一次即可，这次填写会作为新导出文档的初始学习记忆。

## 「加入文档」窗口加宽

- 窗口宽度上限从 480px 提升到 688px；窄窗口下左右仍各留至少 12px。
- 学习模式的四个单选选项在宽窗口一行放四个，720px 以下变两列，420px 以下变一列；学习目标、偏好与补充说明占满整行，长文件名、失败原因和进度条更好读。
- 只有内容区滚动，标题和关闭按钮固定；删除确认等其它弹窗与记忆编辑表单保持原尺寸。

## 阅读助手与多文件提问的预算

- 「设置 → AI」里的两组预算默认值改为各项上限：
  - 阅读助手：页图 10 次、证据页 40 页、证据文字 120000 字符、PDF 读取 60 次、API 检索 8 轮；搜索扫描 500 页、搜索时间 30 秒。
  - 多文件提问：同时运行 4 个、最多等待 16 个。
- 搜索时间改用**秒**显示和输入，可精确到 0.001 秒（例如 10.025 秒），内部仍按毫秒记录，保存后重开显示不变。
- 两组各加了「恢复本组默认」，只重置这一组；点窗口底部的「保存」才真正写入，直接关闭设置会保留原来的值。任何一项填得不合法时整页不会保存，并展开对应分组、标出字段、把焦点放回输入框。
- 旧配置里的值原样保留：以前保存过的小预算、非整数步进的字符预算（例如 24567）都不会被改成上限。

## 术语

- 设置里原来的「每题阅读预算」改为「阅读助手每次对话」，七个字段统一为「/ 每次对话」，其中搜索页数和搜索时间注明「按单次搜索」。

## 对话模式模型抽屉

- 模型与思考强度抽屉的最下一行右侧新增「确定」：点它（或按 Tab 到它后按 Enter / Space）只收起抽屉并把焦点还给模型按钮。选择和以前一样在点选的当下就生效，确定不会重复提交、不会发送消息，也不会改全局预设。
- 阅读助手、翻译与模拟测试的模型抽屉保持原来位置与行为。

## 说明

- 模拟测试的规划和出题继续使用自己独立的预算，不受「阅读助手每次对话」这组设置影响。
- 数据库结构与 `PRAGMA user_version`（仍为 1）、数据目录、本机存储键、备份格式与模型调用协议均未变，旧书库、设置与备份可直接沿用。
- 升级后第一次启动会按既有机制清理一次浏览器缓存，界面首开可能稍慢；书库、设置与密钥都不受影响。
- 预算变大意味着单次提问可能更慢、更耗额度；取消、超时、排队与附件上限等保护保持不变，不承诺每次用满。
- 本次没有新增 Python / npm 依赖。
