# 1.2.4

修复 1.2.3 里「模拟测试」在真实 API 下出题失败的问题。

## 修复

- **输出长度上限**：Harness 的默认单次输出上限是 4096 token，5 道题的 JSON 经常被截断，模型最后一轮只剩一句旁白。现在 `harness/runtime.mjs` 支持请求自带 `maxTokens`，出题调用显式使用 **8192**（阅读助手、对话、记忆等不受影响，仍是 4096）。
- **工具预算**：出题批次从 18 次阅读 / 5 轮提高到 **24 次 / 8 轮**，并在取证规则里写明「最多检索 4 次，之后必须直接输出 JSON」，避免模型把轮次全耗在检索上。
- **真实模型验证**：用 DeepSeek（`deepseek-chat`，8192）跑通一套试卷，前 3 批正常生成 15 题；第 4 批两次失败时按设计保留 15 题、提示「第 4 批生成失败」并给出单批重试，满分按 150 计。计划内「某批失败保留其余」的路径第一次得到真实模型验证。

## 已知

- 个别批次仍可能两次都失败（本次第 4 批），这与提示词/模型行为有关，重试即可；不是整卷失败。
- 1.2.3 的 `SHA256SUMS.txt` 与安装包仍保留，应用内更新器会以 1.2.4 为最新版。
