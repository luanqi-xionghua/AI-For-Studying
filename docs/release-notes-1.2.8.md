# 1.2.8

修复两个用户反馈（首次打开内容区空白、设置页一直闪），并做了一轮整体排查：修掉 2 个安全问题、3 个常用功能失灵，加上崩溃/卡死自动恢复与本机日志。

## 两个已知问题

### 首次打开：侧栏正常、内容区空白

- **原因**：本机服务以前不给 `index.html` 发缓存头，浏览器内核会按“文件年龄的 10%”直接复用旧的入口页。应用内更新或覆盖安装后马上启动，页面仍是旧版，旧版去请求新版里已删掉的懒加载文件（404），内容区就只剩外壳；过一阵再重开才恢复。实测 1.2.6 → 1.2.7 覆盖安装后首开，加载的是旧入口，打开设置时请求的文件 404。
- **修复**：
  - `index.html` 每次重新验证（`no-cache`，没变时回 304），带哈希的 `/assets/` 长缓存；
  - 升级后第一次启动按版本清理一次浏览器缓存（只清缓存，书库、设置、本机存储都不动）；
  - 所有懒加载界面加了加载态、自动重试、失败卡片；刚启动时遇到文件缺失会自动刷新一次；
  - 新装第一次打开（文档库还是空的）也显示“加入文档”的引导，不再只剩一张淡淡的背景线稿。

### 打开设置后页面一直闪

- **原因**：暖色极简 / 铅笔草稿的背景动画在设置窗打开时仍然每秒重画 60 次整窗画布，上面再叠一层半透明遮罩。在显卡加速不可用的电脑上（驱动被列入黑名单、远程桌面等），设置一打开帧率从 29 掉到 5，画面隔帧刷新，看起来就是一直在闪。
- **修复**：设置、加入文档、移除确认这类弹窗打开时背景动画暂停，关上后从停下的地方接着画；设置里悬停预览的缩略图最多 30 帧。同样条件下设置打开时帧率回到 55。

## 安全

- 本机服务拒绝 `\\主机\共享` 这类路径：以前一个特制的图片地址就能让 Windows 去连外部共享并发送当前账户的登录凭据。
- AI 回答里的网络图片不再自动加载，改成“[图片：说明]”链接，点了才用浏览器打开，防止文档里藏的指令借图片地址把对话内容带出去。

## 修复

- AI 回答、Markdown 文档、PDF 里的外部链接点了没反应 → 现在用系统浏览器打开。
- 双击两次快捷方式会弹出 Python 错误窗口 → 现在把已打开的窗口叫到前面；端口被其他程序占用时给出能看懂的说明；端口记录文件损坏时自动换新端口。
- 关窗时最后一两秒的改动（阅读位置、对话、笔迹、记忆）可能没存上 → 关窗前先把这些写完（最多等 1.5 秒）。
- 界面进程崩溃或长时间无响应（约 45 秒）时自动重新加载并提示；连续出问题会换一个新的页面进程。
- 页面重新加载后第一次提问报“本机连接已关闭” → 新页面会等旧连接收尾后接上。
- 对话模式的临时文档，断线一次后会一直显示“正在转换”、发不出消息 → 已修。
- 模拟测试：开始出题时保存失败会让“开始”按钮永远灰着 → 现在退回设置页并说明原因。
- 资料检索：同步中途状态查询失败会一直显示“正在同步” → 已修。
- 划词翻译：连续划几处会占满 AI 请求名额，导致其他功能报“AI 请求过多” → 换选区时停掉上一条。
- 本机接口出错时不再显示 JSON 语法错误，改为显示状态码。

## 本机日志

新增 `%APPDATA%\com.phydog.reading.python\logs\app.log`（最多 4 份 × 512 KB）：记录界面错误、懒加载失败、崩溃恢复、缓存清理等。写入前已去掉会话密钥、API Key 和用户目录，只保存在本机，不上传。遇到问题时可以把它发给开发者。
