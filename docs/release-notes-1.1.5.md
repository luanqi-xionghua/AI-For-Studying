# 阅迁星穹 1.1.5

本次发布在 1.1.1 的基础上扩展了**对话模式**：可以带图片、带文档库文档、带电脑上的临时文档提问；一次提问最多对比 3 本文档，并在回答里给出〔《书名》第 N 页〕式的引用。对话页新增常驻的会话附属栏，同时调整了学习记忆的写入规则。数据格式与 1.1.1 兼容，可直接覆盖升级。

## 对话模式：三类附件

- **图片**：输入栏的图片按钮、`Ctrl+V` 粘贴或拖入图片，最多 6 张、合计 8 MB（按压缩后计算）；缩略图可单张移除，也会显示预算。图片只跟随下一条问题；重开应用后不保留原图，只在消息上留「曾附 N 张图片」的标记。当前模型不识图时按钮会说明原因，带图发送会被拦截并提示换识图模型或移除图片。
- **文档库文档**：📚 按钮搜索、多选，最多 3 份（与临时文档合计），整段会话有效，重开应用自动恢复。只附 1 本时直接流式作答；附 2–3 本时，先分别为每一本整理证据，再合成一份带页码 / 行号引用的对比回答；每本的检索进度、未能读取的原因、可折叠的「参考原文」与本次调用合计都显示在回答下方。
- **临时文档**：⤒ 按钮选择电脑上的 PDF、Markdown 或 Word，只对本次运行有效：不加入文档库、不进备份，文件名只留在内存，界面上显示为「临时文档 N」。Word 会用本机 Office / WPS 或 LibreOffice 转成 PDF，chip 上显示转换阶段；移除 chip、删除会话或退出应用后临时文件会被清理。加密、超大、扩展名不符、非 UTF-8 的 Markdown 都会给出固定提示，提示里不会出现本机路径。

## 对话模式：会话附属栏

- 对话页左侧常驻会话列表：新建、按标题搜索、切换、重命名（`F2` 或 ✎，≤28 字）、删除；当前会话高亮，回答中的会话带标记，相对时间每分钟刷新；最多保留最近 40 段。
- 可以收起；窗口变窄（对话页宽度小于 860px）时自动变成抽屉，`Esc` 关闭并把焦点交还给「对话列表」按钮。
- 页头的「历史」弹层已移除，说明与状态行移到标题右侧。

## 学习记忆写入规则

- 选「文档 A 的记忆」→ 写文档 A 和全局；选「全局记忆」→ 只写全局；选「不使用记忆」→ 不写。
- **只要附件栏里有图片或文档（包括已失效的条目），这一轮只读取记忆、不写入任何学习记忆**，消息下方标注「本轮带附件 · 未写入学习记忆」。
- 重新回答同一轮时只替换待总结项，不重复追加、不新增证据、不重复计问题数；全局记忆读取失败时不会用空内容覆盖原有记忆。

## 界面与体验

- 对话页说明与状态行移到页头标题右侧，附属栏更早开始、整体更高；附属栏宽度调整为 230px。
- 文档库选择弹层里的复选框复原为方形，修复了与行标题错位、互相遮挡的问题。
- 模型开始回答但还没有输出时，消息区显示「**模型正在思考中…**」提示（带读屏状态与减弱动画适配）。
- 修复背景动画（Dijkstra 最短路径场景）画到终点时数组越界导致控制台报错、动画卡顿的问题。

## 隐私与临时文件

- 附件只在本机与你配置的模型服务商之间传输；临时文档走本机后端的临时目录，接口不接收路径，前端只拿到不透明句柄。
- 临时文档不进文档库、不进「导出文档库备份」；应用启动、页面断开、退出、删除会话或移除 chip 时都会清理 `chat-temp/`。
- 文档库文档在对话模式里是只读附件：不改变阅读进度，也不产生阅读学习事件。

## 数据与升级

- 数据目录仍为 `%APPDATA%\com.phydog.reading.python`，环境变量仍为 `KAIZHI_*`，SQLite `user_version` 仍为 1。
- 旧书库、学习记忆、对话模式记录与备份可直接使用；新增字段都是可选的，回退到旧版本时会被安全忽略。
- 已安装 1.1.1 的用户可以在应用内「检查更新」升级到 1.1.5，更新器会校验 Release 附件的 SHA-256 后再安装。
