# 1.2.5

模拟测试的体验修正（来自真机试用反馈）。

## 修改

- **选项公式**：选项文字改用与题干相同的 Markdown/KaTeX 渲染；模型输出的 `\(…\)`、`\[…\]` 会先归一成 `$…$`、`$$…$$`，不再显示原始 LaTeX。
- **交卷前不判对错**：单选不再「选中即判」，选项红绿、每题判定与顶部分数都要等到交卷后才出现；交卷前只显示「已完成 m / n」。
- **「显示答案」按钮**：每题右上角的小箭头改成文字按钮；未交卷时点击提示「先交卷，再查看答案。」，交卷后可正常展开/收起答案。
- **判定颜色**：交卷后「回答正确」绿色、「回答错误」红色、漏选warning 色，卡片边框同步。

## 说明

- 判分语义变化：`scoreQuestion` 的「已判」只在交卷后为真，`liveScore` 在交卷前为 0；交卷结算（`scoreExam`）不变。
- 测试：前端 579 项（更新了单选判分与「展开后锁定」的用例），后端 88 项。
