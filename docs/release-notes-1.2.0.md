# 阅迁星穹 1.2.0

这次更新加入「资料检索」：不开文档，直接从三个公开的中大资料库里找试卷、答案、笔记和课件。

## 新增：资料检索

侧栏新增「资料检索」页（也可以在空白处右键进入）。输入课程或关键词，例如「计算机网络 期末试卷」「线代 课后答案」，就能拿到可点开的链接。

- **三个来源**：OpenISE（中大智能工程学院课程资料）、SYSU-Exam（历年期末试卷）、破壁计划（arxiv.jaison.ink）。三个来源里都有的同一份文件会合成一行，并给出镜像按钮——GitHub 打不开时可以点「破壁计划镜像」。
- **本机索引**：第一次使用点「同步资料索引」，读取三个站点的公开文件目录（约 3000 条，只读文件列表，不下载任何文件）。之后搜索全部在本机完成，几毫秒出结果，断网也能搜。索引超过 1 分钟才允许再次更新，超过 7 天会在页面上提示。
- **先看你有什么**：文档库里已经有的书排在最前面，点「打开」直接进阅读器；网络结果里若有同名文件，会标「你已有」。
- **找不到就说找不到**：匹配不足时直接说明，不会硬凑不相关的资料；同时给出改写建议。
- **只给链接**：点「在 GitHub 打开」或「在破壁计划打开」用系统默认浏览器打开，应用不下载、不预览、不把文件加进书库。链接只允许打开 github.com 和 arxiv.jaison.ink。
- **断网 / 限流怎么办**：已有的索引照常可搜；只有部分来源失败时，其余来源仍会更新，页面上方会说明是哪几个。

## AI 辅助（可选）

配置了 AI 预设时，搜索会多两步，用的是阅读助手预设对应的小模型，用量记在「资料检索」里：

1. **改写查询**：先把你的口语改写成「规范课程名 + 资料类型」。例如「计网 期末」→「计算机网络 期末试卷」，「高数 答案」→「高等数学 答案」。页面上会写明「已按「…」检索」；改写失败、超时或改写后没结果，会自动退回你的原话再搜一次。
2. **挑选并说明理由**：在第一页的前 12 条里重新排序，并为每条写一句理由（例如「2014 年真题，附答案」）。

模型只能在你已经搜出来的候选里排序和解释，**不会生成链接，也不会编造候选之外的资料**；失败、超时、输出超长都静默回落到本地顺序。结果上方的「AI 辅助」开关可以随时关掉，关掉后不再发出任何模型请求。

没有配置 AI 预设时，检索、文档库置顶、「你已有」、打开链接全部照常可用，只是没有改写和理由。

## 数据与隐私

- 目录缓存在数据目录的 `materials.sqlite3`，只是缓存：不进文档库备份，恢复备份也不会替换它。可以在页面上「⋯ → 清空本地索引」，或退出后删掉这个文件。
- 只有你点「同步 / 更新索引」时才会联网，启动应用时不会。请求只带应用名作为 User-Agent，不带账号、密钥、搜索词或任何文档信息；界面本身不直接联网。
- 你的文档库只在本机参与匹配，书名不会发给任何网站或模型。
- 开着「AI 辅助」时，搜索词和至多 12 条候选资料的标题、课程、类别、格式、年份会发给你自己配置的模型服务商。

## 兼容性与升级

- 文档库、学习记忆、对话模式记录、AI 预设与密钥全部不变，直接覆盖安装即可。
- `library.sqlite3` 的 schema 与 `user_version` 没有改动；资料索引是独立的新文件。
- 没有任何新依赖，也不需要另装运行环境。

## 已知限制

- 只索引文件名和元数据，不索引 PDF 正文：能回答「有没有这份资料」，不能回答「哪份资料里讲了某个定理」。
- 破壁计划的下载接口需要登录，所以应用只给页面链接，不承诺能直接下载。
- 破壁计划是个人站点，接口没有稳定性承诺；它变化时会显示「部分来源没有连上」，旧索引照常可用。
- GitHub 未登录访问每小时限 60 次，一次同步只用 2 次；被限流时会保留 GitHub 的旧数据并提示等待时间。
- 课程简称靠一张内置对照表（线代、高数、计网、模电、概统、大物、史纲、马原、毛概、习概、军理等）；配置了 AI 预设后，表里没有的说法也能由模型改写成规范课程名。
