# 1.2.6

模拟测试的真实模型出题修复与一轮排查（详见 `docs/bug-report-1.2.6.md`）。

## 修复

- **真实模型出题失败（0/20「模型返回的不是有效的 JSON」）**：根因有两个，都在工具循环的最后一轮——思考内容和正文共用输出上限，思考「高」时最后一轮被截断；模型用满 8 轮工具后，最后一轮请求不再带工具，DeepSeek 把工具调用标记当正文吐出来。现在开了思考会多留输出余量（16 384；最高档 32 768），工具循环没有给出 JSON 时，用本批已读到的原文再发一次「不带工具、只输出 JSON」的收尾请求。开发副本用 deepseek-flash（思考「中」→ 高）实测出满 20 题。
- **交卷后不能展开答案、不能给大题自评**：结果页「回看全部题目」里的「显示答案」与 0–10 分自评恢复可用；离开结果页后仍是只读。
- **失败批次的单批重试**：刷新或重开后从试卷记录恢复失败批次；部分成功直接进作答页时，作答页也会显示「重新生成第 n 批」（交卷后不显示）。重试成功后失败提示消失，已作答的题不受影响。
- **出题区文案**：失败、停止、等待降级、半成品各有结论，不再残留「正在准备出题…」。
- **导出确认**：只有一类未完成时只写那一类（大题写「未自评」）；两类都有时文案不变。
- **选项无障碍**：选项改为 `role="button"`，不再把 Markdown/公式放进 `<button>`；支持 Enter / 空格选择，点到选项里的链接或代码复制按钮不会误选。
- **后台出题的提示**：切到别的页面或打开原书时出完的「已出好」等提示，回到模拟测试页时补发。
- 出题用量按每一轮累加并记入试卷；评分要点不再显示成「1. 1.」。

## 新增

- 模拟测试的模型抽屉右下角加「确定」：收起抽屉并保留已选模型；没有可用模型时不可点。阅读助手、翻译、对话模式里的模型抽屉不变。
- 开发用的出题调试记录（默认关闭）：`localStorage.setItem('kaizhi.exam.debug.v1', '1')` 后，每次模型调用往控制台写一行 `[exam-debug]`。

## 说明

- 不改 `library.sqlite3` 的 schema 与 `user_version`，不新增依赖；Harness、文档会话、`providers.mjs`、`complete.ts` 未改。
- 推荐设置：deepseek-flash 思考「低」最快且稳定；「高」可用但每批约 35–47 秒。deepseek-v4-pro 思考「低 / 高」单批耗时长，可能逼近 240 秒的批次超时，不推荐用来出题。
- 测试：前端 612 项（新增 33 项），后端 88 项。
